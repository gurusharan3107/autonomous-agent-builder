# Development Routing — autonomous-agent-builder source

When working ON this repository (fixing bugs, improving, or building the autonomous-agent-builder product itself), read **`AGENTS.md`** from the project root — not the project-level `CLAUDE.md`.

**Why:** The project's `CLAUDE.md` is the Builder runtime contract for the Claude Agent SDK lane. It contains instructions for the agents that the builder orchestrates when running user tasks. It is NOT the instruction surface for Claude doing development work on the builder source.

**`AGENTS.md`** is the correct instruction surface for development work on this repo.
